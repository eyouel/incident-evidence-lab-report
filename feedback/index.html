Can a rejected answer become a supported one?

A missing completion record does not prove that work failed. This lab lets a local model request evidence, checks its claims, and measures what happens when evidence is removed and restored.

Method and trust boundary

Only a bounded recognizable final proposal can receive feedback: up to 16 KiB, 2,048 nodes and 12 levels, after native action-envelope checks. A schema-invalid proposal stays invalid until the model changes it. Malformed transport, unsafe or ambiguous actions and terminal execution stops remain fatal. Feedback is at most 4 KiB, uses static public rules, and has no access to golden outcomes, unqueried records or the evaluator.

The same installed Qwen3 8B thinking profile T is used in fresh contexts, with native tool calls and exact complete-input admission. No hidden reasoning is published or returned in history. Each trial permits two submissions and eight generations, with the existing 12-query/64-KiB total evidence budget, 600-second trial/evidence clocks, 300-second requests and 8,192 output tokens inside 32,768 context tokens. No clock or counter resets on rejection.

Verification and limitations

741 tests passed in 150.52 seconds from a clean source-only export. No skips or failures. Targeted development tests overlap this suite. A separate pinned-Docker assembled mock passed with four scripted local HTTP replies, two broker queries and two separately authored scripted submissions; it is not live-model evidence.

Same-machine reproduction used 179 source-only files, pinned Python 3.12 dependencies already installed, and verified imports from the exported src directory. Existing Docker/runtime/model assets were reused. Historical capture-backed experiment commands require the preserved predecessor evidence; fixture workflows and synthetic software tests are source-only reproducible. This is not independent outside reproduction.

Read-only automated review inspected the actual diff, historical rejection records and tests. It found and prompted fixes to serialization, validator-versus-checker labels, feedback dispatch status, extra-generation accounting and a setup-value measurement. It did not independently execute inference or endorse results as an outside human reviewer. Final record reconciliation found all 20 paired initial request hashes equal, but only four pairs had identical first proposal objects. Those first-pass differences precede feedback and cannot be attributed to it. All 145 exact input measurements matched runtime-reported prompt counts; 55 frozen source inputs and 4,007 historical files remained unchanged.

This is one quantized local model, one machine and known synthetic cases. It does not establish production reliability, unseen-case accuracy or a general advantage from thinking or feedback. Fixed rules, mocks, real-model inference and saved Java replay remain separate. API approval remains revoked; subscription-backed incident execution remains disabled.
